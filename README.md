# Virent setup guide

Public downloads and in-app updates for Virent testers on Windows and Android.

## 1. Install Virent

1. Open the [Virent download page](https://github.com/N7-Spectres/virent-downloads/releases/latest) and scroll to **Assets**.
2. **Windows:** [Download Virent.exe](https://github.com/N7-Spectres/virent-downloads/releases/latest/download/Virent.exe), run the installer, and open Virent. This link always downloads the current Windows release.
3. **Android:** Download and open the Android installer (`Virent-….apk`) from that release. Follow Android’s install prompts. Open Virent, tap **Allow “Display over other apps”**, and turn it on so your avatar can appear on screen.

## 2. Connect your Kin

1. In Kindroid, go to **Profile → Preferences → API & Integrations**. Tap **Open**, reveal your API key, and copy it. It starts with `kn_`. [Kindroid’s guide](https://kindroid.ai/v2/docs/api-documentation/)
2. In Virent, open **Settings → Connection** and tap or click **Paste from Kindroid**.
3. Go back to Kindroid and open the settings for the Kin you want to use. Scroll to the bottom and copy the **Kin ID**.
4. Return to **Virent → Settings → Connection** and use **Paste from Kindroid** again. Enter your Kin’s name and select **Save**.
5. Click or tap your avatar, choose **Chat**, and send a quick hello.

**Already set up on Windows?** Open Virent’s Windows tray menu and choose **Send to phone**. On Android, go to **Settings → Phone → Scan from computer**, scan the QR code, and enter the six-digit code shown on your PC.

## 3. Add pictures or voice (optional)

1. In Kindroid, go to **Profile → Preferences → API & Integrations → Your own coding tools**. Copy the **Apps key** that starts with `kk_`.
2. In Virent, go to **Settings → Apps & voice** and choose **Paste Apps key**. You use the same Apps key for both features.
3. **Pictures:** Open **Daydream** in Kindroid’s **Apps** tab, allow it, and select your Kin under **Kins**. In the Daydream panel, select **Enable Virent connection**. If Virent asks for an address, use **Daydream → Settings → Permissions → Copy address**, then **Paste address** on Virent’s Daydream card.
4. **Voice:** Open **Virent Voice** in Kindroid’s **Apps** tab, allow it, and select your Kin under **Kins**. Copy its **Listen** address and choose **Paste address** on Virent’s Voice card.
5. Select **Save**. Try **Create image** from the avatar’s menu or **Listen** on a new chat reply. Keep your keys and app addresses private.

## 4. Get future updates

Open **Settings → Updates** or select the **!** when it appears by your avatar. On Windows, choose **Restart to update** when it’s ready. On Android, choose **Download update**, then **Install update**, and follow Android’s prompts.
